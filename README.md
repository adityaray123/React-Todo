# React Todo App 📝

A simple and responsive Todo application built with **React**.  
Users can add, edit, mark as completed, and delete tasks with a clean and minimal UI.

---

## 🚀 Features

- ➕ Add new todos
- ✅ Mark todos as complete / incomplete
- ✏️ Edit existing todos
- 🗑️ Delete todos
